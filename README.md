Thanks to @bokub/ha-linky https://github.com/bokub/ha-linky
This is an extenstion to the OG ha-linky but exposes yesterday's data as sensor, which allows you to add custom logic on top :D

sensor.linky_yesterday_kwh — Linky Yesterday Consumption
sensor.linky_yesterday_cost — Linky Yesterday Cost (with overhead)

*overhead = subscription fee + tariff <br />
